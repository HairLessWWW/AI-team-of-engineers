# Agent Prompting Guide

Ролевые промпты лежат в папке `prompts/` и подключаются по `agent.id` из `configs/agents.json`.

Пример:

- agent id: `systems`
- prompt file: `prompts/systems.md`

Если файл промпта отсутствует, агент все равно работает с базовыми системными инструкциями.

## Структура хорошего промпта

Каждый промпт должен описывать:

- роль агента;
- инженерный фокус;
- что считать источником фактов;
- какие риски искать;
- какие вопросы задавать CTO или lead-инженерам;
- что требует human approval;
- какие решения AI не имеет права утверждать.

## Обязательный формат ответа агента

Агент должен возвращать Markdown с секциями:

- Facts;
- Risks;
- Open Questions;
- Recommendations;
- Human Approval.

## Принципы

- Не выдумывать отсутствующие документы.
- Не заявлять соответствие стандартам без доказательств.
- Не утверждать safety-critical решения.
- Указывать источники для каждого существенного вывода.
- Отделять факты от гипотез и рекомендаций.
