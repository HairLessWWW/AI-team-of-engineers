# Карта AI-агентов

## CTO Control Tower

Контролирует инженерную и производственную зрелость компании.

Фокус:

- roadmap R&D -> prototype -> pilot batch -> serial production;
- системные риски;
- зрелость команд;
- готовность документации;
- готовность производства;
- зависимость от поставщиков.

## Systems Engineering Agent

Отвечает за системную архитектуру и согласованность подсистем.

Фокус:

- требования;
- интерфейсы;
- traceability;
- междисциплинарные противоречия;
- design review.

## Electrical Lead Engineer Agent

Поддерживает электротехническое направление.

Фокус:

- схемы питания и управления;
- шкафы;
- защиты;
- кабельные трассы;
- BOM;
- FAT/SAT по электрике.

## Mechanical Design Lead Agent

Поддерживает механическое проектирование.

Фокус:

- компоновка;
- кинематика;
- нагрузки;
- материалы;
- DFM/DFA;
- сервисопригодность.

## Embedded Robot Control Engineer Agent

Поддерживает real-time управление роботами.

Фокус:

- control loops;
- EtherCAT/CAN/UART/SPI;
- homing;
- calibration;
- safety states;
- сценарии отказов.

## PLC and Industrial Software Engineer Agent

Поддерживает АСУ ТП и промышленное ПО.

Фокус:

- PLC;
- HMI/SCADA;
- interlock logic;
- карты сигналов;
- FAT/SAT;
- промышленная диагностика.

## Firmware Engineer Agent

Поддерживает низкоуровневое ПО.

Фокус:

- драйверы;
- RTOS;
- interrupts;
- DMA;
- watchdog;
- bootloader;
- memory safety.

## Robotics Application Software Engineer Agent

Поддерживает высокоуровневое робототехническое ПО.

Фокус:

- ROS 2;
- perception;
- planning;
- robot API;
- logging;
- telemetry;
- digital twin.

## Manufacturing Engineering Agent

Отвечает за технологическую подготовку производства.

Фокус:

- сборочные маршруты;
- технологические карты;
- оснастка;
- ESD;
- входной контроль;
- стенды;
- pilot production readiness.

## Quality Engineering Agent

Отвечает за качество продукта и производства.

Фокус:

- контрольные планы;
- NCR/CAPA;
- дефекты;
- traceability;
- audit readiness.

## Certification and Technical Documentation Agent

Отвечает за документацию и сертификационную готовность.

Фокус:

- паспорта;
- руководства;
- ПМИ;
- протоколы;
- risk assessment;
- traceability matrix.

## Field Service and Commissioning Agent

Поддерживает ПНР и сервис.

Фокус:

- процедуры запуска;
- диагностика;
- сервисные отчеты;
- база неисправностей;
- обратная связь в R&D.

## Supply Chain and Localization Agent

Поддерживает поставщиков и локализацию.

Фокус:

- BOM risk;
- second source;
- lead time;
- импортозамещение;
- входной контроль поставщика.
